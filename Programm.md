## 2. Снимок проекта (стек и структура)

- **Название:** "React Questions Cards" — приложение флеш-карточек с вопросами по React (вопрос/ответ/описание/ресурсы/уровень сложности/статус "выучено").
- **Стек:** Vite 8, React 19.2, react-router-dom 7, react-toastify, lucide-react, CSS Modules. Бэкенд — `json-server` (фейковый REST API поверх `src/db.json`), запускается `npm run server` (порт 8801), фронт — `npm run dev`.
- **`API_URL`** — `src/constants/index.js` → `http://localhost:8801`.
- **Точка входа:** `src/main.jsx` → `src/App.jsx` (роуты) → `src/components/MainLayout/MainLayout.jsx` (общий каркас: Header, `<Outlet/>` в `<Suspense>`, ToastContainer, footer).
- **Роуты** (`src/App.jsx`): `/` HomePage · `/addquestion` (lazy) · `/questions/:id` QuestionPage · `/editquestion/:id` EditQuestionPage · `/forbidden` заглушка · `*` NotFoundPage.
- **Структура папок:**
  - `src/components/<Name>/` — UI-компоненты, каждый: `Name.jsx` + `Name.module.css` + `index.jsx` (barrel-экспорт).
  - `src/components/pages/<Name>Page/` — страницы, тот же паттерн.
  - `src/hooks/useFetch.js` — общий хук для запросов (лоадер/ошибка/toast/искусственная задержка).
  - `src/helper/delayFn.js` — `await delayFn(ms)`, промис-задержка для учебной наглядности лоадеров.
  - `src/constants/index.js` — только `API_URL`.
  - `src/db.json` — данные json-server (коллекция `react`).
